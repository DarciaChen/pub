# FBI談判協商術

**作者:** 克里斯‧佛斯

---

### 深化摘要

前FBI首席人質談判專家的實戰心法,核心信念是:**談判本質是情緒管理,不是邏輯辯論**。人在感覺不被理解、被逼迫時,理性思考會關閉,任何邏輯論證都無用武之地。因此必須先用「戰術同理心」讓對方感覺被聽懂,對方的防衛心才會鬆動,理性溝通的大門才會打開。書中工具環環相扣:標籤化說出對方情緒→鏡像模仿引導對方多說→校準式問句讓對方主動幫你解題→引導對方說出「沒錯」而非「你說得對」,確認對方真正認同而非敷衍。

### 值得學習的地方與實例

1. **標籤化(Labeling)——先說出對方的情緒**
   實例:客戶因設備當機動怒時,先說「聽起來這次當機打亂了你的生產排程,你現在一定很焦急」,而非急著解釋原因,對方的敵意會明顯降低,更願意配合排查。

2. **鏡像模仿(Mirroring)——重複關鍵字挖資訊**
   實例:客戶說「這批控制器的反應時間太慢了」,回應「太慢了?」(重複最後幾字),客戶通常會不自覺補充更多細節,如「對,尤其是溫度驟降時反應明顯延遲」,幫助你更快抓到真正問題。

3. **校準式問句——把難題丟回給對方**
   實例:客戶要求超出合約範圍的免費維修時,不直接拒絕,而問「如果我幫你做這個,我要怎麼跟我主管解釋這超出保固範圍?」,常能引導客戶自己提出折衷方案。

4. **「不」比「是」更安全**
   實例:與其問客戶「你要不要現在下單?」(容易感覺被迫),不如問「現在下單會不會太急?」,讓客戶先說「不會」,反而更容易順勢往前推進。

5. **That's right 而非 You're right**
   實例:向客戶總結完他的需求後,若客戶回應「對,就是這樣,你完全說中我的困擾」(That's right),代表真正達成共識;若只回「你說得對」(You're right)則可能只是敷衍,仍需進一步確認需求。
