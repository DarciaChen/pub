# 快思慢想

**作者:** 丹尼爾‧康納曼

---

### 深化摘要

康納曼(諾貝爾經濟學獎得主)提出人腦有兩套思考系統:**系統一**快速、直覺、自動,但容易被偏誤誤導;**系統二**緩慢、費力、邏輯性強,但天生「懶惰」,傾向讓系統一代勞決策。書中系統性整理了數十種認知偏誤,是理解「為什麼人會做出不理性決定」的底層科學基礎,也解釋了席爾迪尼六大原則為何有效——它們都精準命中系統一的自動化捷徑。

### 值得學習的地方與實例

1. **錨定效應(Anchoring)——第一個數字定調全局**
   實例:報價時先提出較高的定錨價格(即使對方會殺價),最終成交價通常仍高於「先提低價再往上加」的策略;技術方案提案時先展示「高階版」報價,再介紹「標準版」,標準版會顯得相對划算。

2. **損失規避(Loss Aversion)——怕失去比想獲得更有力**
   實例:行銷文案寫「不升級控制系統,每年恐因故障停機損失 X 萬元」,比「升級後每年可節省 X 萬元」更能促動決策,因為避免損失的心理驅力更強。

3. **框架效應(Framing)——同樣資訊,說法不同結果不同**
   實例:「這款產品良率 95%」比「這款產品不良率 5%」聽起來更值得信賴,即使數字完全相同;客戶溝通時選擇正向框架陳述數據能降低疑慮。

4. **可得性捷思(Availability Heuristic)——容易想起的事被高估**
   實例:客戶因近期看過新聞報導某類設備起火意外,即使機率極低,仍對同類產品產生過度疑慮——此時提供具體、易記的安全數據或案例故事,比純統計數字更能對抗這種偏誤。

5. **稟賦效應延伸——展示 vs. 試用的差異**
   實例:讓客戶「試用」設備一段時間再決定是否採購,比單純展示規格更容易成交,因為一旦開始使用,客戶會不自覺提高對這項產品的主觀價值評估。
