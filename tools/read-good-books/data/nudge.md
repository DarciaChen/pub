# 推力

**作者:** 理查‧塞勒、卡斯‧桑思坦

---

### 深化摘要

行為經濟學代表作,提出「自由家長制」(Libertarian Paternalism)概念:在不剝奪選擇自由的前提下,透過「選擇架構」(choice architecture)的設計,引導人做出對自己(或設計者期望)更好的決定。核心洞察是:**人很少主動做選擇,大多順著預設路徑走**。因此「預設選項」的設計權力,遠比多數人想像的更具影響力。

### 值得學習的地方與實例

1. **預設選項的力量**
   實例:歐洲國家器官捐贈「預設同意、可選退出」的國家捐贈率遠高於「預設不同意、需主動加入」的國家,差距可達數十個百分比;報價單上把「建議方案」設為預設勾選項,而非要求客戶主動勾選加購項目,採用率會明顯提高。

2. **簡化決策路徑**
   實例:退休金自動加入計畫(而非要求員工主動申請)大幅提高員工儲蓄參與率;技術支援流程中,提供「一鍵預約回訪」按鈕而非要求客戶自行填寫多欄位表單,能提高客戶完成後續動作的機率。

3. **社會規範提示**
   實例:電費帳單附上「你家用電量高於同社區平均值」的提示,能有效促使家戶節電;業務提案中引用「同產業已有多少百分比客戶採用此方案」,比單純介紹功能更具說服力。

4. **適時的提醒與時機**
   實例:繳稅提醒信若在「截止日前一週」而非「截止日前一個月」寄送,回應率更高,因為越接近截止日,人的注意力越集中;客戶合約續約提醒也適合抓在到期前的關鍵時間點發送,而非過早提醒導致被忽略。

5. **化繁為簡的表格設計**
   實例:美國大學入學申請流程若把複雜的助學金申請表簡化為預先填好部分資訊的版本,申請完成率大幅提升;技術報價單若能事先幫客戶標好「建議規格」欄位,而非要求客戶從零開始選擇,能減少決策疲勞導致的放棄。
