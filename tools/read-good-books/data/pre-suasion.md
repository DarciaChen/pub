# 鋪陳力

**作者:** 羅伯特‧席爾迪尼

---

### 深化摘要

席爾迪尼在《影響力》之後的重要續作,主張真正決定說服成敗的關鍵時刻,其實發生在「提出請求之前」。核心概念是 **「注意力等於重要性」(Attention = Importance)**——人腦會把當下聚焦的事物,誤判為與眼前決策最相關的因素。因此高明的說服者,會在正式提案前先「鋪陳」對方的注意力焦點,讓對方在還沒聽到內容前,心理狀態就已經被引導到有利的方向。

### 值得學習的地方與實例

1. **鋪陳提問——先問一個定調問題**
   實例:研究顯示,先問受訪者「你認為自己是願意助人的人嗎?」,之後再提出借用手機的請求,答應率大幅提高,因為對方已被引導進入「我是樂於助人」的自我認知;業務上可先問客戶「貴公司對設備穩定度的要求是不是特別高?」,再介紹強調穩定度的方案。

2. **私有性事件——讓對方自己想通**
   實例:與其直接告訴客戶「這款產品品質很好」,不如先請客戶回想「你之前設備故障造成的停機損失大概多少?」,讓客戶自己得出「穩定度很重要」的結論,說服力遠勝過直接陳述。

3. **環境線索的鋪陳**
   實例:研究發現,家具網店背景若用「柔軟雲朵」圖案,顧客會更傾向選擇舒適型沙發;若背景用「硬幣」圖案,顧客則更在意價格——業務簡報或提案文件中選用的視覺元素(如強調穩定的齒輪圖 vs. 強調省錢的數字圖),都在無形中鋪陳客戶的判斷框架。

4. **時機選擇——注意力窗口**
   實例:在客戶剛經歷一次設備故障、對「穩定性」特別敏感的當下提出升級方案,遠比平時隨機推銷更容易成交,因為此刻客戶的注意力已自然聚焦在你想強調的價值上。

5. **關聯性管理——用詞選擇的影響**
   實例:形容同一產品時,用「經過完整驗證」vs.「新推出」兩種說法,會分別鋪陳出「可靠但可能過時」與「創新但可能不穩定」兩種截然不同的心理預期——精準選字能事先框定客戶對產品的期待方向。
