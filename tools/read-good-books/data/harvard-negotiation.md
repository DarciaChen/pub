# 哈佛這樣教談判力

**作者:** 羅傑‧費雪、威廉‧尤瑞

---

### 深化摘要

本書由哈佛談判專案發展而成,核心翻轉了「談判 = 意志力拉鋸」的舊觀念,主張談判應該是「共同解決問題」的過程。四大要素環環相扣:把人與問題分開處理情緒;聚焦利益而非表面立場;先擴散選項再收斂;用雙方都認可的客觀標準(市場行情、先例、專業意見)做為裁決依據,而非誰更堅持。書中另提出的 **BATNA** 概念,徹底改變談判者的心態——你的底氣不是來自「不能沒有這筆交易」,而是來自「我知道談不成時我還有更好的選擇」。

### 值得學習的地方與實例

1. **BATNA 決定底氣**
   實例:客戶殺價前,先盤點「若這次談不成,我方可轉單其他供應商的成本與時間差」,若備案夠強,議價空間就能守住;反之若明知自己沒有替代方案,反而更容易被牽著走。

2. **立場 vs. 利益——挖掘背後動機**
   實例:客戶說「我要降價 10%」(立場),深入詢問後發現真正的利益是「這季採購預算已經吃緊」——於是可提出「分兩期付款」而非直接降價,同樣滿足客戶利益,卻不必犧牲毛利。

3. **人與問題分開**
   實例:客戶因產品故障而情緒激動指責時,先處理情緒(「這確實造成你很大的困擾,我理解」),再回到問題本身(故障原因與解法),避免把「情緒發洩」誤判為「立場對抗」而陷入防衛。

4. **創造選項再決定**
   實例:與供應商議價時,先列出「降價、延長保固、免運費、加送備品」等多個選項讓對方參考,而非只咬死「一定要降價」,反而更容易在其中一項達成共識。

5. **客觀標準化解僵局**
   實例:雙方對於延遲交貨的賠償金額有爭議時,引用合約中的行業慣例條款或第三方仲裁機構的標準計算方式,而非各自堅持己見,能加速達成共識。
