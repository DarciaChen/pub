# 為什麼談判在哈佛總是最後才教

**作者:** 史都華‧戴蒙

---

### 深化摘要

戴蒙的核心主張是「談判不是邏輯遊戲,而是心理遊戲」——真正決定談判結果的不是誰的論點更正確,而是你是否理解對方腦中的認知框架、情緒需求與自我形象。他反對一次性大幅讓步的做法,主張用「漸進式」的小步協商累積信任;同時強調要善用對方自己認可的標準(而非外部客觀標準)去說服對方,因為人更容易被「自己的話反過來說服自己」。

### 值得學習的地方與實例

1. **漸進式協商——小步累積信任**
   實例:與長期客戶協商年度合約時,不要求一次談定所有條件,先就付款週期達成共識,建立信任後再談單價與交期,成功率遠高於一次性全面攤牌。

2. **用對方自己的標準說服對方**
   實例:客戶堅持某項規格,引用該客戶公司過去發布的採購標準文件中的類似條款來對照說明,比引用你自己公司的規格書更容易被接受。

3. **情感優先於邏輯**
   實例:與堅持己見的採購主管談判時,先肯定對方「你在這個決策上承擔的壓力我完全理解」,滿足對方的自我形象與面子需求後,對方反而更願意在條件上讓步。

4. **找出對方認為的「公平」定義**
   實例:客戶認為「公平」是同業報價的平均值,而非成本加成——先了解對方心中的公平標準,再針對這個標準做論述,比堅持自己的定價邏輯更有效。

5. **問題導向而非權力對抗**
   實例:遇到強勢客戶施壓砍價,不與其正面對抗權力(如搬出合約條款強硬回應),而是問「你希望這次採購達成什麼目標?」,把對抗轉為共同解題。
