# 影響力

**作者:** 羅伯特‧席爾迪尼

---

### 深化摘要

書的核心主張:人類大腦在資訊爆炸的環境中,演化出一套「捷徑判斷法則」(click-whirr,喀嚓-嗡嗡反應),讓我們不必每件事都深思熟慮就能快速決策。這套機制平時很有效率,但也正因為是「自動化反應」,才會被有心人士刻意觸發、利用。七大原則依觸發的心理機制可分三類:

- **義務感驅動**:互惠(欠人情要還)、承諾與一致性(要對得起自己說過的話)
- **資訊捷徑驅動**:社會認同(別人都這樣做,應該沒錯)、權威(專家講的應該對)
- **價值判斷捷徑驅動**:喜好(我信任喜歡的人)、稀缺(越少越珍貴)、一致性/團結(自己人比外人可信)

### 值得學習的地方與實例

1. **互惠——先給小惠再提要求**
   實例:超市試吃攤位讓人先嚐一口,拿了試吃品的人購買率明顯提高;業務上,先免費幫客戶做一次小型故障診斷或提供一份技術白皮書,再談後續合作案,成交率會提升。

2. **承諾與一致性——先拿到小的「是」**
   實例:慈善募款先請對方簽署「支持環保」的請願書(無成本承諾),之後再邀請捐款,捐款率顯著提高;業務上先讓客戶填一份簡短的「需求評估表」,後續提案的接受度會比直接推銷高。

3. **社會認同——在模糊情境中最有效**
   實例:飯店房間放「多數房客重複使用毛巾」的卡片,比單純講環保訴求更能提高毛巾回收率;技術支援情境中,告訴猶豫的客戶「多數同產業客戶都選擇這款控制器」,比條列規格更有說服力。

4. **稀缺性——限量與截止日期**
   實例:電商網站顯示「僅剩3件庫存」,轉換率明顯提升;業務上如實告知「這批模組因缺料只剩少量現貨,下批到貨要等6週」,能促使猶豫的客戶提早下單(前提是資訊真實)。

5. **權威——象徵比實質更有效**
   實例:白袍的醫生代言比一般人講同樣的健康建議更有說服力;技術文件若附上第三方認證標章(如 CE、UL)或引用權威機構的檢測報告,能大幅降低客戶的疑慮。
