# 誰說人是理性的!

**作者:** 丹‧艾瑞利

---

### 深化摘要

行為經濟學經典,透過大量實驗證明人類的不理性行為並非隨機,而是**系統性、可預測的**。書中打破「人是理性計算者」的經濟學假設,指出人普遍依賴相對比較(而非絕對價值)做決策、對「免費」有不成比例的過度反應、且社會關係與市場交易的規則一旦混淆,反而會破壞原本的善意與投入感。

### 值得學習的地方與實例

1. **誘餌選項(Decoy Effect)——用比較引導選擇**
   實例:某雜誌訂閱方案原本只有「電子版 59 美元」與「電子+紙本 125 美元」,加入一個「純紙本 125 美元」的誘餌選項後(同樣金額但明顯較差),選擇「電子+紙本」的人數大幅增加;報價單設計三個方案時,中間方案的存在往往是為了襯托你真正想推的高階方案。

2. **免費的誘惑力**
   實例:實驗中一顆高級巧克力賣15美分、普通巧克力賣1美分時,多數人選高級款;但當兩者都降價1美分(高級款變14美分、普通款變免費)後,多數人反而搶著拿免費的普通款——「免費加購小零件」的行銷手法比同等折扣更能刺激購買。

3. **社會規範 vs. 市場規範**
   實例:某托兒所為了解決家長接送遲到問題,實施遲到罰款制度,結果遲到情況反而變本加厲——因為家長把「愧疚感」(社會規範)轉換成了「付費就沒關係」(市場規範);對長期客戶的售後服務若過度強調「這是額外收費項目」,反而可能破壞原本靠人情維繫的信任關係。

4. **稟賦效應——擁有感放大主觀價值**
   實例:實驗中,擁有某商品的人開出的售價,通常是未擁有者願付價格的兩倍以上;提供客戶「免費試用兩週」的設備,試用期滿後客戶因已產生「擁有感」,退回設備的意願會明顯降低。

5. **價格的相對性——沒有絕對只有比較**
   實例:同一支手錶單獨展示時,顧客難以判斷是否值得3萬元;但若旁邊擺放一支5萬元的類似款式,3萬元的手錶立刻顯得「划算」——業務提案時適度展示「高規格/高價位」的對照方案,能讓主推方案顯得更合理。
