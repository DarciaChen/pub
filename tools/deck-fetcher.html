🎨 名畫牌庫抓取器

直接呼叫 Wikimedia Commons 官方 API 讀取分類頁裡的圖片，不用你手動一張張複製。 有些博物館分類（例如梵谷、孟克）底下是「每幅畫各自一個子分類」的整理方式， 這個工具會先抓分類直屬的圖，抓完之後自動往下鑽子分類（一次處理 5 個）， 不夠按「載入更多」繼續，直到抓完整個分類（含所有子分類）。 抓回來的每張圖會自動標示授權（綠色 OK／紅色需人工確認），紅色的預設不勾選，你可以自己決定要不要留。 孟克那筆改用比較大的「Paintings by Edvard Munch」總分類——Wikimedia 上找不到乾淨的「只限 Nasjonalmuseet」分類，這樣會混到其他館藏（如 Munchmuseet），你抓回來之後可以自己篩掉不要的。
